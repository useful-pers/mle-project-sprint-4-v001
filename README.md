# Подготовка виртуальной машины

## Склонируйте репозиторий

Склонируйте репозиторий проекта:

```
git clone https://github.com/yandex-praktikum/mle-project-sprint-4-v001.git
```

## Активируйте виртуальное окружение

Используйте то же самое виртуальное окружение, что и созданное для работы с уроками. Если его не существует, то его следует создать.

Создать новое виртуальное окружение можно командой:

```
python3 -m venv env_recsys_start
```

После его инициализации следующей командой

```
. env_recsys_start/bin/activate
```

установите в него необходимые Python-пакеты следующей командой

```
pip install -r requirements.txt
```

### Скачайте файлы с данными

Для начала работы понадобится три файла с данными:
- [tracks.parquet](https://storage.yandexcloud.net/mle-data/ym/tracks.parquet)

Скачайте их в директорию локального репозитория. Для удобства вы можете воспользоваться командой wget:

```
wget https://storage.yandexcloud.net/mle-data/ym/tracks.parquet
```

# Сервис рекомендаций

Код сервиса рекомендаций находится в файле `recommendations_service.py`.

В рамках проекта реализован сервис рекомендаций, который объединяет
офлайн- и онлайн-рекомендации.

Сервис состоит из трёх FastAPI-приложений:
- `recommendations_service.py` — основной сервис рекомендаций
- `features_service.py` — Feature Store (похожие объекты, item2item)
- `events_service.py` — Event Store (последние события пользователей)


Данные для сервиса хранятся в S3-хранилище.

## Подготовка окружения


1. Скопируйте файл `env_template` в `.env`
2. Заполните пустые значения переменных окружения
3. Активируйте виртуальное окружение и установите зависимости (описание в начале README.md).

## Запуск сервисов

Каждый сервис запускается в отдельном терминале. Не забудьте проверить, что каждый терминал открылся в папке проекта и активировано виртуальное окружение.

1. Feature Store
```
uvicorn features_service:app --port 8010 
```

Сервис предоставляет эндпоинт /similar_items и загружает данные
о похожих объектах из S3 при старте.

2. Event Store
```
uvicorn events_service:app --port 8020 
```

Сервис хранит последние события пользователей в памяти
и предоставляет эндпоинты /put и /get.

3. Сервис рекомендаций
```
uvicorn recommendations_service:app --port 8000 
```

При запуске сервис загружает офлайн-рекомендации из S3 и предоставляет следующие методы:

/recommendations_offline

/recommendations_online

/recommendations

/health

## Стратегия смешивания рекомендаций (blending)

Итоговые рекомендации формируются путём смешивания онлайн-
и офлайн-рекомендаций по следующему правилу:
- онлайн-рекомендации размещаются на нечётных позициях (1, 3, 5, …)
- офлайн-рекомендации размещаются на чётных позициях (2, 4, 6, …)
- после объединения удаляются дубликаты
- итоговый список ограничивается длиной k

Если онлайн-рекомендации отсутствуют, сервис возвращает только офлайн-рекомендации.

# Инструкции для тестирования сервиса

Код для тестирования сервиса находится в файле `test_service.py`.

Перед запуском тестов убедитесь, что все три сервиса запущены
и доступны по следующим адресам:
- http://127.0.0.1:8000
- http://127.0.0.1:8010
- http://127.0.0.1:8020

Для запуска тестов выполните в отдельном терминале:

``` 
python test_service.py
``` 

В ходе выполнения:
- проверяется доступность сервиса рекомендаций
- тестируются три сценария:
- пользователь без персональных рекомендаций
- пользователь с персональными рекомендациями без онлайн-истории
- пользователь с персональными рекомендациями и онлайн-историей

Вывод тестового скрипта автоматически сохраняется в файл test_service.log
в корне проекта.
